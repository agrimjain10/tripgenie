# Photography

Wandiamo uses real photographs, not AI-generated travel imagery. Images are downloaded into `frontend/public/images` so page rendering does not depend on a third-party image server. A photo may represent the named destination or general landscape/travel inspiration; generic images are labeled as inspiration in discovery.
